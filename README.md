# Fotheged Translator

Translate English into Fotheged, the scholarly tongue of the Avaggdu of Urthe, with rooted runes, pronunciation, voice and a searchable dictionary.

**Install on Android:** open the GitHub Pages address in Chrome, tap ⋮ and choose **Install app**. It then works offline.

This repository is published from the Urthe project. `index.html` is generated from the translator there, so edit it through that project rather than by hand.
